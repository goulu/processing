# Sitemap

Visualisation graphique et cartographie sous forme de graphe dynamique à base de physique de force d'un site web crawlé.

Par **Marcel Salathé** & **Philippe Guglielmetti (Dr. Goulu)**.

---

## 📂 Contenu du dossier

| Fichier | Description |
| :--- | :--- |
| **`sitemap.pde`** | Sketch **Processing (Java)** de crawling et rendu du graphe HTML. |

---

## 🚀 Utilisation (Processing Java)

1. Ouvrez `sitemap.pde` dans l'IDE [Processing](https://processing.org/).
2. Bibliothèques requises : `htmlparser`, `traer.physics`, `traer.animation`.
3. Lancez avec `Ctrl+R` / `Cmd+R`.
