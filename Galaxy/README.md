# Galaxy

Simulation de galaxie spirale en 3D / 2D avec rotation stellaire sur orbites elliptiques différentielles et twisting factor.

Par **Philippe Guglielmetti (Dr. Goulu)**, 2008.

Adapté d'une démo originale LUA/Demoniak 3D.

---

## 📂 Contenu du dossier

| Fichier | Description |
| :--- | :--- |
| **`Galaxy.pde`** | Sketch **Processing (Java)** utilisant le rendu 3D / OpenGL. |
| **`flares.jpg`** | Texture de flare lumineux pour les étoiles. |

---

## 🚀 Utilisation (Processing Java)

1. Ouvrez `Galaxy.pde` dans l'IDE [Processing](https://processing.org/).
2. Bibliothèques requises : `gifAnimation` (optionnel pour l'export), OpenGL / P3D.
3. Touches de contrôle interactives : touches fléchées pour modifier les paramètres de la galaxie (twist, vitesse, ratio elliptique).
