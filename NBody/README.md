# NBody

Simulation de dynamique gravitationnelle à $N$-corps utilisant un moteur de particules (`traer.physics`) et configuré via un fichier de système stellaire en XML.

Par **Philippe Guglielmetti (Dr. Goulu)**.

---

## 📂 Contenu du dossier

| Fichier | Description |
| :--- | :--- |
| **`NBody.pde`** | Sketch **Processing (Java)** de simulation physique. |
| **`system.xml`** | Définition des corps célestes (masses, positions initiales, vitesses, rayons). |

---

## 🚀 Utilisation (Processing Java)

1. Ouvrez `NBody.pde` dans l'IDE [Processing](https://processing.org/).
2. Bibliothèque requise : `traer.physics`.
3. Lancez avec `Ctrl+R` / `Cmd+R`.
